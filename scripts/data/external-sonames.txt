# Libraries that are provided by packages outside the repositories configured
# in the maintenance container (chaotic-aur, archlinuxcn, arch4edu and the AUR),
# but are installed on the machines that use this repository.
#
# They cannot be discovered from the container's pacman file databases, so
# without this list every ffmpeg-full release is reported as needing a rebuild
# and the maintenance job dispatches a pointless rebuild with a pkgrel bump on
# every run.
#
# Refresh procedure: run the maintenance workflow, and for every soname it
# reports as no longer provided, verify the owning package on the target
# machine:
#
#   pacman -Qoq /usr/lib/<soname>          # owning package
#   pacman -Si <package> | grep '软件库\|Repository'
#
# Add the soname here when the owner comes from a third-party repository or the
# AUR. When the owner is a package in one of the container's repositories, the
# report is a real finding and the package does need a rebuild.
